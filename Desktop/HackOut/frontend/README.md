# ☀️ SUN THEORY — Frontend (Next.js 14 Operations Console)

This directory contains the user interface and operations control room for **SUN THEORY**.

For the comprehensive project overview, system architecture, machine learning model specifications, and full setup guide, please refer to the **[Root Documentation (README.md)](../README.md)**.

---

## ⚡ Quickstart

### 1. Install Dependencies
```bash
npm install
```

### 2. Run the Development Server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

> [!NOTE]
> Make sure the FastAPI backend is running on `http://127.0.0.1:8000` before accessing the dashboard. See [Backend Setup](../README.md#step-1-backend-setup-fastapi).

---

## 🛠️ Tech Stack & Key Libraries
- **Framework**: Next.js 14 (App Router)
- **UI & Visualization**: Recharts, Lucide Icons, Glassmorphic CSS
- **Styling**: Tailwind CSS
- **Type Safety**: TypeScript
